## Featured Project

**Transforms** - [github.com/deniz-hofmeister/transforms](https://github.com/deniz-hofmeister/transforms)
Pure Rust library for coordinate frame transformations in robotics and computer vision.
- Middleware-independent (no ROS2/DDS dependencies)
- `no_std` compatible for embedded systems
- Memory safe with `#![forbid(unsafe_code)]`
- O(log n) lookups, SLERP interpolation, automatic frame chaining
